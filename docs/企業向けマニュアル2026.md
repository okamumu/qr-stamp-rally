# しくみ（1分で分かる版）

- 参加者（主に学生）は**名札にQRコード**が入っています
- スタンプの代わりに、**貴社の端末（スマホ・タブレット）で参加者の名札QRを
  読み取っていただく**だけです。紙のスタンプ台・印鑑はありません
- 一定数の企業ブースを回った参加者は、総合受付で抽選（景品）に参加できます。
  **抽選・景品はすべて総合受付で行います**ので、ブース側の作業は読み取りのみです

# 前日（10/16 設営時）：ブース登録　※その場で1〜2分

1. 実行委員から**登録用紙（1社1枚・QRコード入り）**をお渡しします
2. 当日お使いになる端末で用紙のQRを読み、開いたページで
   **社名を入力 → 用紙に印字された登録キーを入力 → 登録**
3. **貴社ブース専用の読み取り画面（URLとQR）が発行されます。
   その端末でブックマーク（ホーム画面に追加）**してください
4. 社名を直したいときは、同じページで**同じキー＋新しい社名**を送信すれば
   修正できます（URLは変わりません）

※登録用紙・キーは貴社ブース専用の鍵です。**参加者には見せない**でください。

# 当日：読み取り

1. ブックマークした読み取り画面を開く
2. 「**次の学生を読み取る**」を押してカメラを起動 → **参加者の名札のQR**に向ける
3. 緑色で「**スタンプしました**」と出たら完了（カメラは自動で閉じます）
4. 次の参加者には、もう一度「次の学生を読み取る」を押す

- 同じ方を二度読んでも大丈夫です（「すでに押してあります」と出るだけです）
- 読み取りのタイミング（説明の前か後か）や、お声がけの内容は貴社の自由です

# うまくいかないとき

| 症状 | 対応 |
|---|---|
| カメラでQRがうまく読めない | その参加者に「総合受付へお越しください」とお伝えください（受付側で記録します） |
| 「未登録です。先に総合受付で参加登録をお願いします」と表示される | その参加者に「総合受付で参加登録をしてからもう一度どうぞ」とお伝えください |
| 端末の電池切れ・故障 | 別の端末で同じ画面を開けばそのまま続行できます。登録用紙のQRから登録ページを開き、**社名を空のまま送信**すると発行済みQRを再表示できます |
| 画面が開かない・つながらない | お近くの実行委員か総合受付へお声がけください（障害時の代替手段はこちらでご用意し、その場でご案内します） |
