## F. 年度固有の値を設定へ追い出す

テンプレート化の程度は高く、年度切替で触るのは実質4か所。

| 値 | 場所 | 状態 |
|---|---|---|
| `BASE`（サイトURL）、`COMPANIES`（8社） | `gen_codes.py:24, 28-38` | 既に定数 |
| `TITLE`「2026年度（第77回）…」、`DATE`、`WIFI` | `make_nametags.py:25-27` | 既に定数 |
| `ADMIN_KEY`, `NEED1 = 4` | `lib/config.php:10, 13` | 既に定数 |
| **大会名の見出し2行** | **`index.html:7`（title）と `:45`** | **コード本体に直書き。ここだけ要修正** |

`index.html` の2行を `config` の定数へ追い出せば「設定ファイルの書き換えだけ」で年度が変わる。
`NEED1` と「全社で2回目」は定数・`count()` 参照なので**社数には依存しない**（良い作り）。
会場名「ミライクリエ」の埋め込みは**ゼロ**。
